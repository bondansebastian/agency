## Music

Every video carries the same bed, so the sound is part of the IgnisLabs identity.

| Element | Value |
| --- | --- |
| Track | `assets/ignis-ambient-bed.mp3`, about 6 minutes, generated by `scripts/make-bed.py` (no samples, no third-party licence) |
| Mood | Calm, warm, professional: soft pad, quiet bass, gentle plucks, light reverb. 84 BPM, Cmaj7 - Am7 - Fmaj7 - G6, repeating every 8 bars |
| Mix | Cut or looped to the video length, 2 s fade in, 3 s fade out, about -24 LUFS integrated, true peak -3 dBTP (`addMusic` in `lib.mjs`). The video stream is copied, not re-encoded |
| Rules | Only this bed, no voice-over. To change the sound, edit `make-bed.py` and replace the mp3 |

Pace: a caption stays on screen about one second per three words plus one second. Typing is 110 ms per character. Cards stay 4 to 12 seconds. A whole feature video should be 2 to 5 minutes.
